# 🃏 Memory Game

Un gioco di memoria con levcarte, realizzato con HTML, CSS e JavaScript vanilla.  
Questo è uno dei miei primi progetti, sviluppato per mettere in pratica le basi del frontend.

---

## 🎮 Come si gioca

- Gira le carte e trova tutte le coppie uguali
- Il timer inizia al primo click — hai **3 minuti** per completare il gioco
- Completa il tabellone prima che scada il tempo per vincere

---

## ✨ Funzionalità

- Griglia 10×3 con 15 coppie di carte raffiguranti animali
- Miscelazione casuale delle carte ad ogni partita
- Countdown con game over allo scadere del tempo
- Effetti sonori (gira carta, coppia trovata, vittoria, game over)
- Musica di sottofondo con toggle on/off
- Popup di benvenuto, vittoria e game over con SweetAlert2
- Pulsante Stop timer
- Regolamento accessibile in-game

---

## 🛠️ Tecnologie

- HTML5
- CSS3
- JavaScript vanilla
- [SweetAlert2](https://sweetalert2.github.io/)
